# rpg-texto
RPG de Texto en Java

Juego de rol por turnos jugado desde consola, desarrollado por estudiante de DAM como proyecto de portfolio.

Características actuales:
3 clases de personaje jugable (Guerrero, Pícaro, Mago), con atributos distintos
Sistema de combate por turnos con probabilidad de fallo
Jerarquía de clases con herencia (Personaje → Jugador/Enemigo)

Próximas funcionalidades:
Inventario (pociones, armas, armaduras)
Sistema de decisiones con consecuencias
4 tipos de enemigo
Interfaz gráfica sencilla
